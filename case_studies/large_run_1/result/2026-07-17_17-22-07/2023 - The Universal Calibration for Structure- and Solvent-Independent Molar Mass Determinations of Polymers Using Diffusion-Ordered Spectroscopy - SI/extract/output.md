## Theoretical Basis

intrinsic viscosity according to Flory: 1

$$[ \eta ] = \frac { 2 . 5 \, N _ { A } v _ { h } } { M } \quad ( 1 )$$

$$[ \eta ] = K \, M ^ { a }$$

From equation (1) and (2) follows equation (3):

$$V _ { h } = \frac { 1 } { 2 . 5 * N _ { A } } K \, M ^ { a + 1 }$$

$$V _ { h } = \frac { 4 } { 3 } \pi \, r _ { h } ^ { 3 }$$

From equation (3) and (4) follows equation (5):

$$K \, M ^ { a + 1 } = \frac { 1 0 } { 3 } \pi \, N _ { A } \, r _ { h } ^ { 3 }$$

$$r _ { h } = \frac { k _ { B } T } { 6 \, \pi \, \eta \, D }$$

including (6) into (5) yields equation (7):

$$K \, M ^ { a + 1 } = \frac { 1 0 } { 3 } \, \pi \, N _ { A } ( \frac { k _ { B } \, T } { 6 \, \pi \, \eta \, D } ) ^ { 3 }$$

For the determination of K2 and a2 the following proportionalities for a given T are used:

$$K _ { 1 } M _ { 1 } ^ { a _ { 1 } + 1 } \sim \frac { 1 } { \eta ^ { 3 } d _ { 1 } ^ { 3 } }$$

$$K _ { 2 } \, M _ { 2 } ^ { a _ { 2 } + 1 } \sim \frac { 1 } { \eta ^ { 3 } d _ { 2 } ^ { 3 } }$$

The ratio of (8a) and (8b) results in (9):

$$\frac { K _ { 1 } M _ { 1 } ^ { a _ { 1 } + 1 } } { K _ { 2 } M _ { 2 } ^ { a _ { 2 } + 1 } } = ( \frac { \eta ^ { 2 } D _ { 2 } } { \eta ^ { 1 } D _ { 1 } } ) ^ { 3 }$$

from Rouse-Zimm model derived: 4,5

Mark-Houwink relation: 2

Stokes-Einstein equation: 3

Including (11) in (9) results in (12):

$$D = c \, M ^ { - b }$$

Resolving (10) to the molar mass yields (11):

$$M = ( \frac { D } { c } ) ^ { - 1 / b }$$

with

$$\frac { K _ { 1 } ( \frac { D _ { 1 } } { c _ { 1 } } ) ^ { - ( a _ { 1 } + 1 ) / b _ { 1 } } } { K _ { 2 } ( \frac { D _ { 2 } } { c _ { 2 } } ) ^ { - ( a _ { 2 } + 1 ) / b _ { 2 } } } = \frac { \eta ^ { 3 } D _ { 2 } ^ { 3 } } { \eta ^ { 3 } D _ { 1 } ^ { 3 } } \\$$

Resolving (12) to D2 is possible by using logarithmic rules:

$$\log \left ( D _ { 2 } \right ) = A + B \log \left ( D _ { 1 } \right )$$

$$A = \frac { b _ { 2 } } { 3 b _ { 2 } - a _ { 2 } - 1 } \{ \log \left ( \frac { K _ { 1 } \eta _ { 1 } ^ { 3 } } { K _ { 2 } \eta _ { 2 } ^ { 3 } } \right ) + \frac { a _ { 1 } + 1 } { b _ { 1 } } \log \left ( c _ { 1 } \right ) - \frac { a _ { 2 } + 1 } { b _ { 2 } } \log \left ( c _ { 2 } \right ) \}$$

$$\frac { } { } \{ \log \left ( \frac { K _ { 1 } \eta _ { 1 } ^ { 3 } } { K _ { 2 } \eta _ { 2 } ^ { 3 } } \right ) + \frac { a _ { 1 } + 1 } { b _ { 1 } } \log \left ( c _ { 1 } \right ) - \frac { a _ { 2 } + 1 } { b _ { 2 } } \log \left ( c _ { 2 } \right ) \} \\ \\ B = \frac { b _ { 2 } ( 3 b _ { 1 } - a _ { 1 } - 1 ) } { b _ { 1 } ( 3 b _ { 2 } - a _ { 2 } - 1 ) }$$

D1 corresponds to the diffusion coefficients of the reference polymer in dependence of Mw. D2 corresponds to the diffusion coefficients of the second polymer in dependence of Mw where the parameters K2 and a2 will be determined.
